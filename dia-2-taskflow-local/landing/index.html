Que es

No es otro gestor de tareas.

Es una bitacora de escritorio para capturar solicitudes, reuniones, seguimientos y trabajo realizado sin convertirlo en deadlines, recordatorios o tableros complejos.

Privacidad

Tus datos se quedan en tu maquina.

01

SQLite local

Clientes, proyectos y entradas se guardan en una base local.

02

Offline first

La app funciona sin LLM y sin conexion obligatoria.

03

Multiusuario

Cada usuario ve solo sus propios registros.

Funciones

Hecha para resumir trabajo.

Clientes y proyectos

CRUD completo y relacion clara: un cliente puede tener varios proyectos.

Entradas de bitacora

Titulo, descripcion, fecha, rango, horas, tipo y estado simple.

Reportes

Resumen semanal, mensual, por proyecto y exportacion CSV/PDF.

Espanol / Ingles

Interfaz bilingue, parser bilingue.

Cambia manualmente el idioma de la interfaz y procesa frases simples en espanol o ingles desde el asistente.

Voz + texto

Dicta si puedes. Escribe siempre.

Usa Web Speech API cuando el WebView lo soporte. Si no esta disponible, el campo manual sigue funcionando como flujo principal.

Distribucion

Placeholder para GitHub Releases.

Abrir Releases
  • Instala Rust, Node.js y dependencias de Tauri.
  • Ejecuta npm install dentro de app/.
  • Usa npm run tauri:build para generar instaladores.
  • Sube los artefactos a GitHub Releases y apunta este boton al release final.
